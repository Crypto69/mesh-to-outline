Mesh to Outline

for Autodesk® Fusion® · version {{VERSION}}

Mesh to Outline cuts a mesh body with a plane and draws the section as a normal sketch of lines, arcs, circles and fitted splines, ready to extrude, loft or dimension. It can also draw a whole stack of sections between two picks and extrude them into one solid body.

It runs only on your computer. It collects no data and needs no internet connection. Privacy policy.

Requirements

  • The current release of Autodesk Fusion, on Windows 64-bit or macOS.
  • Nothing else: everything the add-in needs is inside it.

Where to find it

Mesh tab → Modify panel → Mesh to Outline, next to Convert Mesh. If Fusion's Mesh panel is not found, the button is under Utilities → Add-Ins instead; the Text Commands palette says where.

To turn the add-in off or on: Utilities → Add-Ins → Scripts and Add-Ins → Add-Ins tab → MeshSectionSketch → Stop / Run.

Quick start

  1. Insert → Insert Mesh, and set the units to mm.
  2. For one section or a stack, make a construction plane where you want the cut (Construct → Offset Plane), or use any flat face.
  3. Mesh tab → Modify → Mesh to Outline.
  4. Choose the Action first: Single slice, Stack or X-Ray. Pick the mesh body, then the plane (Single slice, Stack) or the start and end (X-Ray), and click OK.

Settings

SettingDefaultWhat it does
ActionSingle sliceSingle slice: a single sketch. Stack: several sketches on offset planes. X-Ray: a stack between a start and an end pick. It decides which picks the dialog asks for.
Mesh body—The mesh body to cut.
Plane—Single slice and Stack: a construction plane or a flat face to cut on.
Start / End—X-Ray only: a construction plane, a flat face or a click on the mesh. The slices run parallel to the Start plane, or the End plane if Start is a mesh click, so at least one must be a plane or a flat face of a solid. A click on a flat mesh face snaps to that face.
Spacing0.2 mmStack and X-Ray: the distance between sketches.
Sections (count)10Stack only: how many sketches, 2 to 400.
DirectionAlong the normal (+)Stack only: along the plane's normal, against it, or both sides.
Fit tolerance0.08 mmHow far a fitted curve may sit off the raw section.
Join gaps up to2.5 mmLoose ends closer than this are joined, so an outline broken only by hairline cracks comes back as one closed profile. 0 draws exactly what Fusion's own mesh section draws.
Trim slivers up to0 mmCuts out thin out-and-back slivers where the mesh has a double skin. 0.3 mm is a good start on a leaky mesh; 0 leaves the outline as traced.
Outline onlyoffKeep just the outer outline: loose open pieces and inner loops are skipped, so each sketch is one clean profile.
Tidy cornersoffFillets meet their walls tangent and corners meet exactly. The curves of each loop share their end points and every fillet gets a tangent constraint.
Sharpen rounds below0.08 mmShown with Tidy corners. A round that stays within this of its corner is drawn as the sharp corner. 0 keeps every round.
Extrude each sliceoffStack and X-Ray: each sketch is extruded to the next slice and joined into one stepped solid body.
Hide mesh afteroffHides the mesh body when done. The mesh is never deleted.

Messages you may see

MessageWhat to do
Empty cut skippedThe plane misses the mesh there.
WARNING: the outline did not close in N slicesThe mesh has holes wider than Join gaps at those slices. Raise Join gaps to the value the warning gives and run again.
WARNING: N slabs could not be extrudedThe sketch was drawn, but Fusion found no profile to extrude there. The per-slice list says why.
Autodesk Fusion has updated its PythonUpdate Mesh to Outline from the Autodesk Marketplace.
Mesh to Outline is incompleteReinstall Mesh to Outline from the Autodesk Marketplace.
Another add-in has loaded an old copy of numpyTurn that add-in off, restart Fusion, and try again.

Undo and uninstall

Each run adds sketches (and, if ticked, one body) to your design; Undo or deleting them removes them. To uninstall, use the Autodesk Marketplace uninstaller (Windows: Apps & features; macOS: remove the MeshToOutline.bundle folder from ~/Library/Application Support/Autodesk/ApplicationPlugins).
